Core Technology

Gbus — Brokerless Message Bus

Gbus는 여러 프로세스가 데이터를 공유하고 교환할 수 있도록 Pub/Sub을 지원하는 메시지 버스입니다.
중앙에서 메시지를 중계하지 않고 프로세스 사이를 직접 연결합니다.
솔루션의 실시간 처리 계층을 연결하고 고객사 시스템 연계에 활용하는 기반 기술입니다.
